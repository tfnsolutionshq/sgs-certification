# SGS Digital Certificate Portal

A digital certificate management portal for the School of General Studies (SGS).

## Features

- Dashboard with certificate statistics
- Cohort management
- User management
- Certificate type configuration
- Template management
- Signatory management
- Verification logs
- Audit logs
- System settings

## Tech Stack

- React 18
- Vite
- TypeScript
- Tailwind CSS 3.4.19
- React Router DOM

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
